# Tide Pets

Sea creatures that keep you company while you code, in VS Code and JetBrains IDEs, and react to what you're doing. Pick one: **Shelly** the sea turtle, **Bloop** the jellyfish, **Inky** the octopus, **Pinchy** the crab, **Puff** the pufferfish, **Blue** the whale, **Clem** the clownfish, **Sandy** the seahorse or **Finn** the shark.

![The nine pets](docs/pets.png)

| You | Your pet |
| --- | --- |
| Type | Swims faster |
| Save | Does a happy loop and blows bubbles |
| Add errors to the open file | Looks worried; hides when several appear at once (Inky inks, Puff puffs up) |
| Fix all the errors | Celebrates |
| Run a task or run configuration | Cheers when it passes, hides when it fails |
| Run the app | Spins: "It's alive!" |
| Debug | Brings out a magnifying glass |
| Open your AI assistant, or a big block of code appears at once | "Did an AI write that? I won't tell." |
| Open the terminal; run `git push`, tests, installs, `rm -rf` (VS Code) | "Command line time!", "Ship it!", "Fingers crossed!", hides |
| Commit, switch branches | Celebrates, or notices the new branch |
| Undo several times in a row | "Rewinding time?" |
| Switch files | Looks around |
| Code late at night, early in the morning, or for hours | "It's late. The tide's out.", "Stretch break?" |
| Step away for 3 minutes | Naps |
| Click it / double-click it | Does a spin / shows hearts |

**Feed it.** Use **Feed Pet** (the ♥ on the VS Code panel, or right-click the pet in IntelliJ) and a snack sinks down: `{ }`, `[ ]`, `( )`, `< >` or `;`. Your pet swims over and eats it. Every 20th `{` you type drops a crumb too, and a pet that hasn't eaten in an hour asks for one.

![Pets reacting to typing, fixed errors, a new error, failed tests, debugging and being left alone](docs/moods.png)

Made to go with the [Midnight Tide](https://github.com/Chelayel/Midnight-Tide) theme, and works with any theme.

| Editor | Folder | Where the pet lives | Choose, show or hide |
| --- | --- | --- | --- |
| VS Code | [`vscode/`](vscode/) | A **Tide Pets** panel in the Explorer (VS Code doesn't let extensions draw over the editor) | **Tide Pets: Choose Pet** / **Toggle Pet**, or the `tidePets.*` settings |
| JetBrains (2024.2+) | [`intellij/`](intellij/) | Floating at the bottom of the editor: drag it where you want it, or turn on **Swim Around**. It fades and lets clicks through while you work on a line it covers | Right-click the pet or **Tools → Tide Pets**; size and name in **Settings → Tools → Tide Pets** |

## How it's built

Every pet is described once, in [`web/pets.json`](web/pets.json) (generated by [`tools/pets.py`](tools/pets.py)): shapes in a 120x80 box, grouped so each mood can pose a group, with parts that paddle, pulse or sway, and each pet's lines. Two small renderers draw it:

- **VS Code** ([`web/pet.html`](web/pet.html), hosted by [`vscode/extension.js`](vscode/extension.js)): SVG in a webview; the extension posts what you're doing.
- **JetBrains** ([`intellij/`](intellij/)): native Java2D in a layer over the editor (`pet/PetArt.kt`, `PetBrain.kt`, `PetPainter.kt`), fed by IDE listeners in `PetService.kt`.

Adding a pet means adding it to `tools/pets.py`; both IDEs pick it up. `./gradlew renderPreview` in `intellij/` draws every pet in every mood with the JetBrains painter, headlessly:

![Every pet in every mood, drawn by the JetBrains painter](docs/intellij-moods.png)

Run locally:

```
python3 tools/pets.py > web/pets.json          # after changing the art
cd vscode && npx @vscode/vsce package           # tide-pets-<version>.vsix
cd intellij && ./gradlew runIde                 # an IDE sandbox with the plugin
```

## Publishing

A tag publishes both at the tag's version:

```
git tag v0.2.0 && git push origin v0.2.0
```

[`release.yml`](.github/workflows/release.yml) builds and verifies the JetBrains plugin and the VS Code extension, attaches both to a GitHub release, and uploads each to its marketplace only when that marketplace doesn't already have the version, so re-running a tag is safe. A push to `main` that touches either IDE or the page builds them as a check and publishes nothing. Bump `pluginVersion` in `intellij/gradle.properties` and `version` in `vscode/package.json` alongside the tag.

The JetBrains Marketplace only accepts updates through its API: upload the first version by hand at https://plugins.jetbrains.com/plugin/add, using the zip from the release. The VS Code Marketplace creates the extension on its first automated upload.

Store tokens are repository secrets (`gh secret set NAME`, value on standard input):

| Secret | For |
| --- | --- |
| `JETBRAINS_MARKETPLACE_TOKEN` | JetBrains Marketplace, a token from https://plugins.jetbrains.com/author/me/tokens |
| `VSCE_PAT` | VS Code Marketplace, an Azure DevOps PAT with *Marketplace: Manage* on all accessible organizations (retired by Microsoft on 2026-12-01) |
| `AZURE_CLIENT_ID`, `AZURE_TENANT_ID` | VS Code Marketplace through a managed identity instead of the PAT; its federated credential must trust this repository's `marketplace-publish` environment |
| `OVSX_PAT` | Open VSX, optional |

A missing token skips that store with a warning.
